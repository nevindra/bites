# Echo feature inventory

Sources read: echo.labstack.com (docs now publish v5.4.2; v4 is in bug-fix mode to 2026-12-31), pkg.go.dev for echo/v4 (v4.16.3) and echo/v5, github.com/labstack/echo-contrib. Tag `[v4]` or `[v5]` where a feature is version specific. Gaps (what the pages did not state) are listed at the end. Short URL forms: G=https://echo.labstack.com/guide, M=https://echo.labstack.com/middleware, C=https://echo.labstack.com/cookbook, P4=https://pkg.go.dev/github.com/labstack/echo/v4, P5=https://pkg.go.dev/github.com/labstack/echo/v5.

## Routing
- Radix-tree router: zero dynamic memory allocation, route prioritisation; handler signature `func(c *echo.Context) error` [v5] (`echo.Context` interface in v4) [G/routing/]
- Method helpers: e.GET/POST/PUT/DELETE (+PATCH, HEAD, OPTIONS, CONNECT, TRACE; QUERY added v5.3.0), each takes path, handler, route-level middleware [G/routing/, P5]
- e.Add(method, path, h, m...) / e.AddRoute generic registration; AddRouteError returned on bad route [P4, P5]
- e.Any: one handler for all methods incl. non-standard ones; `RouteAny` constant [G/routing/, P5]
- e.Match(methods []string, path, h): handler for listed methods [G/routing/]
- Method-specific route beats Any route on the same path [G/routing/]
- Match types: static, named param `:id`, wildcard `*`; priority static > param > wildcard [G/routing/]
- Path params: c.Param(name), c.ParamOr(name, default), wildcard as c.Param("*"), ParamNames/ParamValues/SetParamNames/SetParamValues [v4] / PathValues, SetPathValues, PathValues.Get/GetOr [v5] [G/routing/, P4, P5]
- e.Group(prefix, middleware...) with shared middleware; nested groups; group has same verb helpers, Any, Match, Use, Static, StaticFS, File, FileFS, RouteNotFound [G/routing/, P4, P5]
- Host-based routing: e.Host(name, m...) returns a group bound to a host with its own router [v4] [P4]
- Virtual hosts [v5]: echo.NewVirtualHostHandler(map host->*Echo) dispatches by host name; unmatched hosts go to the returned Echo [C/subdomain/, P5]
- Route naming: Route{Method, Path, Name}; RouteInfo{Name, Method, Path, Parameters}; name set when registering and used by Reverse [P4, P5]
- e.Reverse(name, params...) builds URL from route name; e.URI(handler, params...) / e.URL(...) from handler [v4]; Routes.Reverse, RouteInfo.Reverse [v5] [P4, P5]
- Reverse inside templates via Context#RouteInfo().Reverse added to template data map [G/templates/]
- Route listing: e.Routes() [v4]; Router.Routes(); Routes.Clone/FilterByMethod/FilterByName/FilterByPath/FindByMethodPath [v5] [P4, P5]
- Context.RouteInfo() returns method/path/name/params of current request (empty before routing or on 404/405) [v5] [P5]
- Context.Path()/SetPath(): registered route path [P4, P5]
- Context.Handler()/SetHandler(), echo.HandlerName(h) [P4, P5]
- Default handlers: NotFoundHandler, MethodNotAllowedHandler; names NotFoundRouteName, MethodNotAllowedRouteName; ContextKeyHeaderAllow [P4, P5]
- e.RouteNotFound(path, h, m...) custom 404 handler per path (incl. "/*") ; `RouteNotFound` constant [P4, P5]
- RouterConfig [v5]: NotFoundHandler, MethodNotAllowedHandler, OptionsMethodHandler, AllowOverwritingRoute, UnescapePathParamValues, UseEscapedPathForMatching, AutoHandleHEAD [P5]
- Pluggable Router interface: NewRouter(e), NewConcurrentRouter (add/remove routes after server start), DefaultRouter.Add/Remove/Route/Routes [v5]; Echo.Routers/Router(), multiple routers by host [v4] [P4, P5]
- e.OnAddRoute (v5) / OnAddRouteHandler (v4): callback when a route is added (validation, logging) [G/customization/, P4, P5]
- Middleware attachment points: e.Pre (before routing), e.Use (after routing), Group.Use, per-route middleware; v5 Echo.Middlewares()/PreMiddlewares() [P5, M/method-override/, M/rewrite/]
- Wrapping net/http: echo.WrapHandler(h), echo.WrapMiddleware(m) [C/embed-resources/, P4]
- MiddlewareConfigurator interface (ToMiddleware) [P5]
- echo.GetPath(r) returns raw or decoded request path [v4] [P4]
- Echo is an http.Handler: e.ServeHTTP, AcquireContext/ReleaseContext, NewContext(r, w) [P4, P5]

## Binding
- Sources: path, query, header, form, JSON, XML bodies; Content-Type selects decoder (json, xml, x-www-form-urlencoded) [G/binding/]
- Tags: `query`, `param`, `header`, `form` (explicit tag required); `json`, `xml` fall back to field name [G/binding/]
- Slices from repeated values (?tag=a&tag=b) [G/binding/]
- c.Bind(&v): order path params, query (GET/DELETE only), body; later overwrite earlier; headers not included [G/binding/]
- Direct binders: echo.BindBody, BindQueryParams, BindPathValues [v5] (BindPathParams v4), BindHeaders; DefaultBinder methods [G/binding/, P4, P5]
- Custom binder: assign e.Binder (Binder interface `Bind(i, c)`); wrap DefaultBinder, fall back on ErrUnsupportedMediaType [G/binding/]
- Fluent ValueBinder: QueryParamsBinder(c), PathValuesBinder(c) [v5] (PathParamsBinder v4), FormFieldBinder(c) [G/binding/]
- BindError() first error, BindErrors() all, FailFast(bool) (default on) [G/binding/]
- Typed methods: Bool/Byte/String/Int, Int8-64, Uint, Uint8-64, Float32/64, Duration, each with Must* (required) and plural slice forms [P4, P5]
- Time(layout), Times, UnixTime, UnixTimeMilli, UnixTimeNano (+Must*); TimeLayout and TimeOpts, TimeLayoutUnixTime* constants [P4, P5]
- BindWithDelimiter("id", &dest, ","), TextUnmarshaler, JSONUnmarshaler, BindUnmarshaler, CustomFunc (+Must*) [G/binding/, P5]
- BindUnmarshaler interface `UnmarshalParam(src string) error` for custom types [G/request/]
- BindingError (Field, Values, embedded HTTPError), NewBindingError, MarshalJSON [P4, P5]
- Generic typed helpers: echo.PathParam[T], PathParamOr, QueryParam[T], QueryParamOr, QueryParams[T], QueryParamsOr, FormValue[T]/FormValueOr/FormValues/FormValuesOr (FormParam* in v4), ParseValue/ParseValueOr/ParseValues/ParseValuesOr, ContextGet[T], ContextGetOr [G/request/, G/context/, P4, P5]
- Security note: bind into a DTO, then copy allowed fields to domain model [G/binding/]
- Config.FormParseMaxMemory [v5] [P5]

- Proxy / WithConfig: Skipper, Balancer (required), RetryCount, RetryFilter, ErrorHandler, Rewrite (wildcard), RegexRewrite, ContextKey "target", Transport, ModifyResponse; HTTP and WebSocket; sets X-Forwarded-Proto and X-Real-IP [M/proxy/]
