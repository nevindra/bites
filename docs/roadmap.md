# Roadmap

What is built next, in order of importance. Decisions live in [`adr/`](adr/); this file holds only what is not built yet. What was built, and when, is in the ADRs and the git history, and from the first tag on the release pages under [`releases/`](releases/).

**There are no milestones** (decided 2026-11-04): what is left is in three tiers by how many applications need it ([ADR 0002](adr/0002-the-reference-workload.md)), [Important](#important-what-most-applications-need), [Fairly important](#fairly-important-what-many-applications-need) and [Nice to have](#nice-to-have-what-few-applications-need), each built in order once the tier before it is done. Breadth is a goal ([ADR 0077](adr/0077-four-principles-in-the-order-they-win.md)), so an item waits for its turn, not to be asked for: each keeps a trigger, which moves it up when it appears. Every item names the frameworks that have it, read from their documentation on 2026-11-03, and on 2026-11-04 for the microservice frameworks ([`docs/research/framework-gap/`](research/framework-gap/report.md)), and the ADR it touches; an item that changes an ADR's rule edits that ADR first, with its evidence, and its design is stress-tested before it is built.

## The first tag

No tag exists yet, here or on the remote, and none is made until the maintainer asks, with the exact version stated first ([ADR 0034](adr/0034-versioning-before-1-0.md)). When it is asked for, in this order:

- **The comparison run** on the bench machine puts the framework beside net/http, Huma, nilo and fib over TCP: the `compare`, `step17` and `profile` phases of `bench/release.sh` ([`bench/README.md`](../bench/README.md#the-release-run)).
- **Its profile starts from a request path with no p99 past the 10% of ADR 0003 behind middleware.** Two causes were found and fixed on 2026-11-05: 80 B of slab room every request with middleware reserved, which made the collector run 40% more often ([`docs/research/middleware-p99/`](research/middleware-p99/report.md)), and the collector halving a busy connection's stack under its wait, which the next request grew back ([ADR 0005](adr/0005-our-own-http1-engine-with-a-goroutine-per-connection.md), [`docs/research/stack-shrink/`](research/stack-shrink/report.md)). One middleware now costs p99 +5% to +10%, three +6% to +9%, and the route with none lost 21% of its p99 ([ADR 0003](adr/0003-the-trade-budget.md)).
- **The release page** [`docs/releases/v0.1.0.md`](releases/v0.1.0.md) takes the run's numbers and, since nothing was released before it, describes what the release holds rather than what changed.
- **The core is tagged, then each module** ([ADR 0070](adr/0070-optional-features-are-modules-under-modules-each-with-its-own-go-mod.md)): until then a module's `replace` line keeps it from being fetched outside the repository.

## Important: what most applications need

Built first, in this order. The agent usability tests ([`docs/research/agent-usability/`](research/agent-usability/report.md)) were closed by the maintainer's decision of 2026-11-04 after five runs, each of whose fixes is built; what an application built on bites stumbles on from now on is fixed as it is found, before any new feature, since principle 1 wins over breadth ([ADR 0077](adr/0077-four-principles-in-the-order-they-win.md)).

1. **Stores shared by several instances over Redis or NATS**: a Redis or Valkey `RateLimitStore` and `OwnerSessionStore`, and a Redis or NATS `Broker`, as modules. The Postgres ones are built (`modules/pgratelimit`, `modules/pgsession`, `modules/pgnotify`; [ADR 0085](adr/0085-a-postgres-rate-limit-store-is-a-module.md), [ADR 0082](adr/0082-a-postgres-session-store-is-a-module.md), [ADR 0081](adr/0081-a-topic-reaches-other-instances-through-a-broker-and-postgres-is-a-module.md)), and a new store runs bitetest's conformance suites, which hold it to its interface ([ADR 0086](adr/0086-a-store-is-held-to-its-interface-by-a-conformance-suite-in-bitetest.md)). Fiber's storage, httprate, Gin's and Hertz's sessions have one ([ADR 0055](adr/0055-rate-limiting-is-a-token-bucket-per-key-with-a-bounded-store.md), [ADR 0056](adr/0056-a-session-is-sealed-in-a-cookie-and-changed-by-returning-its-cookie.md), [ADR 0070](adr/0070-optional-features-are-modules-under-modules-each-with-its-own-go-mod.md)). *Trigger:* an application whose instances share Redis or NATS rather than Postgres, or a fan-out that Postgres's `NOTIFY` cannot carry.

## Fairly important: what many applications need

Built in order once nothing is left under Important; when the trigger written after an item appears, it moves up.

2. **A schedule beyond a fixed interval**: cron expressions, and a job that runs on one instance of several (a lock), on top of `bites.Every` and `bites.Worker`, which are built ([ADR 0079](adr/0079-services-start-after-the-app-binds-and-stop-in-reverse-around-shutdown.md)). Encore has `cron.NewJob`; go-zero documents a Kubernetes CronJob instead, and go-micro schedules in its `agent`, read from its source ([`microservices.md`](research/framework-gap/microservices.md)). *Trigger:* a job that must run at a time of day, or exactly once across instances, which a job safe to run twice does not need.
3. **A way to state a type's whole schema when no method can** (Huma's `SchemaProvider`, Fuego) ([ADR 0015](adr/0015-json-is-our-own-codec-on-jsontext.md)). A body of several shapes, `oneOf` with a `discriminator`, is built: a tagged union ([ADR 0083](adr/0083-a-json-value-of-several-kinds-is-a-tagged-union-of-opt-variants.md)). *Trigger:* a type no method can describe.
4. **Validators for any answer, and writes that check them**: an `ETag` for a JSON answer and `If-Match` on a `PUT` or `PATCH` answered 412, for optimistic concurrency; only `File` does this today. Fiber and Hertz (`etag`) and Huma (`conditional`) have it ([ADR 0064](adr/0064-a-file-answers-its-own-conditional-and-range-requests.md)). *Trigger:* two people overwrite each other's edit of one record.
5. **A map in the query**, `filter[name]=x` and the `deepObject` style. Gin (`QueryMap`), Fiber and Huma have it ([ADR 0042](adr/0042-text-values-are-decoded-by-type.md)). *Trigger:* an API filters by fields the client chooses.
6. **`Idempotency-Key`**: a write repeated with the same key is answered with the first answer. Fiber has it ([ADR 0032](adr/0032-four-first-party-middleware.md)). *Trigger:* an application takes payments or receives webhooks that are retried.
7. **A concurrency limit with a backlog, and load shedding**: at most N requests in a route, the rest queued for a while and then refused with 503 and `Retry-After`; only `Upload` routes have `MaxInFlight`. chi (`Throttle`), Fiber (`loadshed`) and Hertz (Sentinel) have it ([ADR 0024](adr/0024-limits-are-on-by-default.md)). *Trigger:* a handler too costly to run unbounded, such as a report over a year of data.
8. **A request body read as a stream** when it is not multipart: a large `application/octet-stream`, a resumable upload, NDJSON coming in; `Raw` and `[]byte` are read whole up to `MaxBody`. Fiber, Hertz and net/http have it ([ADR 0044](adr/0044-the-body-type-decides-how-a-body-is-read.md)). *Trigger:* an application receives files larger than a sensible `MaxBody`.
9. **An access log that can be shaped**: the fields chosen, paths skipped, bodies dumped up to a bound, the ECS, OpenTelemetry and GCP schemas; `AccessLogOptions` has `Logger` and `Level`. Fiber, Echo and httplog have it ([ADR 0051](adr/0051-a-request-is-observed-when-it-starts-and-when-it-has-really-ended.md)). *Trigger:* the log is too noisy or missing a field someone searches for.
10. **Typed consumers of a message queue**: a handler registered on a topic as a route is, its message type checked at Registration and decoded as a WebSocket message is ([ADR 0036](adr/0036-websocket-routes-are-typed-like-http-routes.md)), with Kafka, NATS, RabbitMQ and the cloud pub/subs as modules. Encore (`pubsub.NewTopic[T]`, typed), go-micro (`broker`, untyped) and go-zero (`kq` for Kafka, `dq` for Beanstalkd, untyped) have it ([`microservices.md`](research/framework-gap/microservices.md)). *Trigger:* an application consumes events another service publishes.
11. **A compressed request body**, `Content-Encoding: gzip` decoded with a bound on its decoded size. Echo (`Decompress`) and Fiber have it ([ADR 0044](adr/0044-the-body-type-decides-how-a-body-is-read.md), [ADR 0024](adr/0024-limits-are-on-by-default.md)). *Trigger:* a client sends one.
12. **A response cache and request coalescing**. Fiber, Gin's cache, Hertz and chi's `stampede` have it. *Trigger:* an expensive read is asked for repeatedly.
13. **The API document for older tools**: OpenAPI 3.0.3 beside 3.1, YAML, tag descriptions, `externalDocs`, `x-` extensions, callbacks and webhooks, OAuth 2 flows and scopes (Huma; Fuego for YAML and tags) ([ADR 0020](adr/0020-descriptions-come-from-registration-and-later-from-doc-comments.md), [ADR 0069](adr/0069-the-api-document-states-what-a-routes-providers-and-middleware-ask-and-answer-and-a-route-can-be-left-out.md)). *Trigger:* a program that reads the document cannot read 3.1 JSON, or needs one of these.
14. **Autobahn conformance.** Its cases echo arbitrary text, and a text message here is JSON both ways ([ADR 0036](adr/0036-websocket-routes-are-typed-like-http-routes.md)), so every text case would fail by design. Running it needs an echo harness at the engine's level, or a message type that sends raw text, which is a decision about ADR 0036. *Trigger:* before 1.0, or a client that fails against the WebSocket engine.
15. **The rest of the production modules, waiting for a deployment that asks**: OpenTelemetry HTTP metrics beside the Prometheus Observer, and the WebSocket metrics of the `SocketObserver` recorded by the OpenTelemetry module too, which today only `Metrics` records ([ADR 0063](adr/0063-opentelemetry-is-a-module-whose-observer-records-the-server-span-and-names-it-to-the-core.md)); a `NOTIFY` sent in the transaction of the write it announces, so a crash between commit and publish cannot lose it ([ADR 0081](adr/0081-a-topic-reaches-other-instances-through-a-broker-and-postgres-is-a-module.md)); and restarting a trace at an internet-facing edge ([ADR 0063](adr/0063-opentelemetry-is-a-module-whose-observer-records-the-server-span-and-names-it-to-the-core.md)); an allow-list of public hosts, RFC 7239 `Forwarded` and an opt-in for `X-Forwarded-Proto` ([ADR 0025](adr/0025-no-proxy-is-trusted-by-default.md)); multipart/byteranges, rejected for now so a request for several ranges is answered whole ([ADR 0064](adr/0064-a-file-answers-its-own-conditional-and-range-requests.md)). *Trigger:* a deployment needs one of them.
16. **Smaller items, each with its own trigger**: routing by host (net/http, Fiber, Echo, chi; [ADR 0018](adr/0018-the-router-follows-servemux-rules.md)) when applications share one app by hostname; an allow-list of `Host` values (Fiber, Gin's secure, Hertz; [ADR 0025](adr/0025-no-proxy-is-trusted-by-default.md)) when an application must refuse a `Host` it does not serve, against DNS rebinding; a reverse proxy with balancers (Fiber, Echo, Hertz; [ADR 0019](adr/0019-plain-http-handlers-are-a-slow-path.md)) when an application fronts another service; JSON Patch and a `PATCH` made from `GET` and `PUT` (Huma `autopatch`; [ADR 0041](adr/0041-presence-is-a-type.md)) when a client sends one; WebSocket subprotocols (Fiber, gorilla, Hertz; [ADR 0046](adr/0046-websocket-origins-and-inbound-limits.md)) when a client needs one; Casbin or Open Policy Agent (Fiber, Echo, Gin, Hertz; [ADR 0048](adr/0048-groups-and-the-order-things-run-in.md)) when the permission table outgrows a `UseEach` function; our own 404 and 405 answers (Gin, Echo, chi, Hertz) when an application needs a page rather than problem+json; a JWT issued and refreshed, PS256 and EdDSA, and a cache of verified tokens (Hertz; [ADR 0062](adr/0062-jwt-verification-is-a-module-whose-key-fixes-the-algorithm.md)) when an application issues tokens to another system.

## Nice to have: what few applications need

What few applications need, often only those facing clients on the internet directly. Built in order after Fairly important; when an application shows the need written after an item, it moves up.

17. **What a server-rendered page needs**: route names and URLs built from them (Echo `Reverse`, Fiber `GetRouteURL`), flash messages and a redirect back (Fiber), the CSRF token from a form field (Fiber, Echo, [ADR 0057](adr/0057-csrf-trusts-the-browsers-origin-and-falls-back-to-a-double-submit-token.md)), and the method override of an HTML form (Echo). *Trigger:* an application renders HTML on the server instead of serving an API to a frontend.
18. **HTTP/2**, h2 over ALPN and h2c, as an engine of its own ([ADR 0017](adr/0017-tls-now-http2-later.md)). net/http, Gin, Echo and Hertz have it. *Trigger:* an application served to browsers directly, without a proxy in front that speaks HTTP/2 to them.
19. **gRPC** served by the app beside its HTTP routes, on the HTTP/2 engine of the item above ([ADR 0017](adr/0017-tls-now-http2-later.md)). Kratos serves HTTP and gRPC from one `.proto` (`google.api.http`), go-micro has `server/grpc`, and go-zero `zrpc` from a `.proto` apart from its `.api` file ([`microservices.md`](research/framework-gap/microservices.md)); grpc-go serves it beside bites on its own listener today. Whether a `.proto` may be the source of a route's types is an open question below. *Trigger:* other services call an application over gRPC, which brings HTTP/2 forward with it.
20. **WebSocket compression**, permessage-deflate in its no-context-takeover mode, with its cost measured ([ADR 0040](adr/0040-no-permessage-deflate-for-now.md)); and the WebSocket extras: a WebSocket behind a reverse proxy (Echo, Hertz), Socket.IO (Fiber), a message type that sends raw text, which Autobahn needs ([ADR 0036](adr/0036-websocket-routes-are-typed-like-http-routes.md)).
21. **Routing extras**: a segment matched by a regular expression or a type, several parameters in one segment, an optional parameter, the `+` wildcard (Fiber, chi); one handler for every method (Gin, Echo, Fiber); an app mounted inside another (Fiber, chi); routes changed while serving (Fiber, Echo v5); routing by a header or an extension (chi) ([ADR 0018](adr/0018-the-router-follows-servemux-rules.md), [ADR 0042](adr/0042-text-values-are-decoded-by-type.md)).
22. **Rewrites and redirects by rule**, and the redirects to HTTPS and to or from `www` (Fiber, Echo, chi, Gin's secure) ([ADR 0018](adr/0018-the-router-follows-servemux-rules.md)).
23. **Protocol answers**: 103 Early Hints (Fiber), HTTP trailers (net/http, Hertz), a connection closed with no answer (Fiber `Drop`) ([ADR 0013](adr/0013-other-statuses-are-wrapper-types.md), [ADR 0030](adr/0030-streaming-is-a-return-type.md)).
24. **Older JSON forms**: JSONP, a prefixed JSON against hijacking, ASCII-only JSON, `?pretty` (Gin, Echo, Fiber) ([ADR 0015](adr/0015-json-is-our-own-codec-on-jsontext.md)).
25. **Operations endpoints of our own**: pprof, expvar, the favicon, selected environment variables (Fiber, chi, gin-contrib, Hertz); pprof and expvar are served today through `stdhttp.Mount`.
26. **Small middleware**: the time a request took and `Server-Timing` as headers (Fiber `responsetime`), pagination read from the query (Fiber `paginate`), any cookie encrypted beyond the session's (Fiber `encryptcookie`, [ADR 0056](adr/0056-a-session-is-sealed-in-a-cookie-and-changed-by-returning-its-cookie.md)), `Access-Control-Allow-Private-Network` (Fiber, Gin's cors).
27. **More credentials**: PASETO (Fiber, Hertz), HTTP Signatures (Gin's `httpsign`), Kerberos and SPNEGO (Fiber) ([ADR 0054](adr/0054-auth-providers-parse-the-credential-and-the-application-verifies-it.md)).
28. **The engine**: several processes on one port with `SO_REUSEPORT` (Fiber, Hertz), a guard for TLS 1.3 early data answered 425 (Fiber) ([ADR 0005](adr/0005-our-own-http1-engine-with-a-goroutine-per-connection.md), [ADR 0017](adr/0017-tls-now-http2-later.md)).
29. **What Huma adds to an answer**: a `$schema` member and a `Link` with `rel="describedby"`, each type's JSON Schema at its own path, transformers after the handler such as a field selection (Huma; Fuego's `OutTransformer`), modifiers of a group's operations.
30. **A certificate from ACME in one call**: `ListenTLS` takes the `*tls.Config` of `autocert.Manager` today; a helper is what Gin's `autotls`, Echo, Fiber and Hertz give ([ADR 0017](adr/0017-tls-now-http2-later.md)). `acme-tls/1` is built and tested against the protocol and has never run against a real certificate authority; that run comes with the helper.
31. **Service registration and discovery**: an app registers itself when it listens, leaves at Shutdown, and resolves another service by name ([ADR 0029](adr/0029-shutdown-drains-and-then-closes.md), [ADR 0052](adr/0052-health-and-readiness-follow-shutdown.md)), each registry a module. Kratos (`registry.Registrar` and `Discovery`, with Consul, etcd, Eureka, Kubernetes, Nacos, Polaris, ServiceComb and ZooKeeper), go-zero (`zrpc`, with etcd, Kubernetes and static endpoints), go-micro (`registry`, with mDNS, Consul, etcd and NATS) and Hertz have it ([`microservices.md`](research/framework-gap/microservices.md)). *Trigger:* services deployed where the platform does not resolve them by name, as Kubernetes DNS does.
32. **Bodies other than JSON**: Protocol Buffers and MessagePack between services, XML, YAML, TOML, CBOR and BSON, and an answer chosen by `Accept`; the body type decides how a body is read, so a format is likely a body type ([ADR 0044](adr/0044-the-body-type-decides-how-a-body-is-read.md)). Kratos (json, protojson, proto, xml, yaml and form, by `Content-Type` and `Accept`), go-micro (codecs by content type), Gin (`Negotiate`), Fiber (`AutoFormat`), Huma and Fuego have it. *Trigger:* a client or another service sends, or asks for, a body that is not JSON.
33. **i18n**: the framework's messages (a problem+json's `detail`, a validation error) in the client's language from `Accept-Language`, and a bundle the application's own messages use ([ADR 0012](adr/0012-client-errors-are-400-problem-json.md)). Gin (gin-contrib `i18n`), Fiber (contrib `i18n`) and Hertz have it; none of the four microservice frameworks does ([`microservices.md`](research/framework-gap/microservices.md)). *Trigger:* an application shows the framework's error messages to people in more than one language.
34. **A database layer**: migrations, a pool reached through a Provider ([ADR 0023](adr/0023-provided-sections-are-checked-at-registration.md)), and perhaps a typed query layer or an ORM; the driver stays the application's choice ([ADR 0002](adr/0002-the-reference-workload.md)), and the layer needs an ADR of its own before anything is built. go-zero (`core/stores` and `goctl model`), Encore (`sqldb` with migrations) and Kratos (Ent in its project template) have one ([`microservices.md`](research/framework-gap/microservices.md)). *Trigger:* applications repeat the same pool and migration wiring.
35. **HTTP/3** ([ADR 0017](adr/0017-tls-now-http2-later.md)). Gin has `RunQUIC`, experimental, on quic-go; Hertz archived its `http3` repository, and none of the four microservice frameworks has it ([`microservices.md`](research/framework-gap/microservices.md)). *Trigger:* the standard library exposes QUIC, or an application's clients are on networks where HTTP/3 measurably helps.
36. **The rest of the engine's optimisation pass and the soft axes not measured yet.** Fewer deadline arms and one read a request fewer were built on 2026-11-04 ([`docs/research/optimisation-pass/`](research/optimisation-pass/report.md), [ADR 0005](adr/0005-our-own-http1-engine-with-a-goroutine-per-connection.md), [ADR 0024](adr/0024-limits-are-on-by-default.md)); left are a smaller idle connection, and the candidates that report ranks and did not build: Registration compiling a shared type once (about 27 µs and 270 allocations a route today), a metrics scrape that escapes each label once a series, and the JWT module's HS256 verify parsing its payload once. Not measured yet: throughput and allocations a request over TLS; throughput and p99 of an upload, of a stream, and of a stream over TLS with its two `setsockopt` calls; idle memory, throughput and p99 with compression on over TCP; throughput and p99 behind the PROXY protocol; WebSocket throughput; Shutdown's own time with 20,000 sockets, whose 6,700 closes a second is arithmetic. Speed ranks last of the principles and the numbers are guards, not goals ([ADR 0003](adr/0003-the-trade-budget.md)). *Trigger:* an application whose load makes latency or memory matter.

## The definition of finished

bites is finished as 1.0 when nothing is left under [Important](#important-what-most-applications-need), the first tag is made, Autobahn conformance runs, the documentation site is published (it is not yet, by the owner's decision of 2026-11-02; `bites-site` renders it, [ADR 0073](adr/0073-the-documentation-is-rendered-to-a-static-site-by-a-program-in-the-repository.md)), the stability of the Go API and the wire is promised, and a final benchmark against net/http, Huma and nilo is written on every axis. Items under Fairly important and Nice to have are built after Important in order, or sooner when their trigger appears, and 1.0 does not wait for them. What waits for a trigger beyond those:

- **Compile-time refusals** through code generation ([ADR 0007](adr/0007-mistakes-are-refused-at-registration.md)): if refusing at start-up proves not enough.

## Not goals

What a principle of [ADR 0077](adr/0077-four-principles-in-the-order-they-win.md) still refuses, written down so it is not asked for again. Each was in the frameworks of [`docs/research/framework-gap/`](research/framework-gap/report.md):

- **A JSON codec swapped in** (sonic, go-json, jsoniter in Gin, Fiber, Echo and Hertz): safety and the agent first, since the 400 that names a field and the refusal of an unexported field depend on the codec being the framework's own ([ADR 0015](adr/0015-json-is-our-own-codec-on-jsontext.md)).
- **Validation by struct tags and go-playground/validator** (Gin, Echo, Fiber, Hertz, Fuego; Huma's own tags): one way to do a thing, since a rule is a type or a method, checked at Registration ([ADR 0021](adr/0021-validation-is-a-method-and-a-few-constraint-types.md)); what tags can state is a method on the type, exclusive bounds, `MultipleOf`, `Unique` and `Members` included.
- **Redirects that add or remove a trailing slash, paths repaired and matched without regard to case** (Gin, Echo, Hertz, Fiber, chi `RedirectSlashes` and `CleanPath`): safety, since a path is matched as sent and an unnormalised one is a 400, because a proxy that normalises differently is how routing is bypassed ([ADR 0018](adr/0018-the-router-follows-servemux-rules.md)).
- **A dependency-injection container, and state and services held by the app** (Fiber `State`, `SharedState`, Gin's and Echo's `Set` and `Get`): one way to do a thing, since a value reaches a handler through a Provider, checked at Registration ([ADR 0023](adr/0023-provided-sections-are-checked-at-registration.md)); services started with the app are a `Service` ([ADR 0079](adr/0079-services-start-after-the-app-binds-and-stop-in-reverse-around-shutdown.md)).
- **Code generated from an IDL** (Hertz with `hz`, Thrift and Protocol Buffers): a second source of truth beside the handler's types, which are the contract an agent reads ([ADR 0007](adr/0007-mistakes-are-refused-at-registration.md)); whether a `.proto` may be the source of a gRPC route's types is an open question below.

## Reopened, not placed

Refused until 2026-11-04 for scope alone, reopened when breadth became a goal ([ADR 0077](adr/0077-four-principles-in-the-order-they-win.md)), and left out of the three tiers by the maintainer's decision of 2026-11-04. Neither is refused or planned: each is placed, with its frameworks, trigger and ADR, if the maintainer asks.

- **Views, layouts and a template engine** (Fiber, Gin, Echo, Hertz; Templ and Gomponents in Fuego and Huma). Today `html/template`'s output is returned as `Bytes`.
- **An HTTP client, with retries and circuit breakers** (Fiber's client and `circuitbreaker`, Hertz's client). `net/http`'s client is used today.

## Open questions

Each is settled as an ADR, or edited into the ADR it names.

- **A `.proto` as the source of a route's types**: gRPC (item 19) is most often served from a `.proto`, and Kratos generates both its HTTP and its gRPC routes from one ([`microservices.md`](research/framework-gap/microservices.md)), while code generated from an IDL is a Not goal because it is a second source of truth beside the handler's types. Whether generated Go types may be a route's Input, with the `.proto` as the one source, is settled before gRPC is built.
- **OAuth 2 in the API document**: `CustomAuth` states `http`, `apiKey`, `mutualTLS` and `openIdConnect` schemes but not OAuth 2, whose flows and scopes would need scopes declared per route ([ADR 0069](adr/0069-the-api-document-states-what-a-routes-providers-and-middleware-ask-and-answer-and-a-route-can-be-left-out.md)); an access token is described as a Bearer token until then.
- **A default in the API document**: built 2026-11-03 for the text Sections (a `Defaults` method on the Section's struct, [ADR 0041](adr/0041-presence-is-a-type.md)). Still open: a default for a JSON `Body` member, which needs the codec to fill an absent member and the fast path to agree with the tokenizer on it, and is refused at Registration until then.
- **The `operationId` check without a document**: two routes whose made ids a generator cannot tell apart (`GET /x` and `GET /x/`) are refused also in an app that never calls `OpenAPI`, as the check of two paths of one shape already is ([ADR 0020](adr/0020-descriptions-come-from-registration-and-later-from-doc-comments.md)); whether both checks should wait for the document is open.
- **`Request.Header` as a scan or an index**: chosen once real middleware shows how many lookups a request makes ([ADR 0022](adr/0022-middleware-sees-a-request-view-and-returns-a-response-value.md)).
