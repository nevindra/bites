# bites is its own project, and nilo is a source of ideas, not an authority

bites is a Go HTTP framework that borrows nilo's central idea (the handler's types are the contract, and a mistake in them is refused before the first request) but none of nilo's decisions. Go and Zig force different trades: a garbage collector where nilo has a request arena, a reflection pass at registration where nilo has the compiler, goroutines where nilo has zio fibers. So an idea taken from nilo is argued again here, as an ADR of this repository with its own evidence, and bites is free to decide the opposite of nilo where Go makes that the better answer. nilo's ADRs are never cited as the reason for anything here.

**The name is bites** (decided 2026-11-04). The module is `github.com/nevindra/bites` and the package is `bites`, so the import path ends in the package's own name and an agent that reads the import never has to guess what goes before the dot. The test package is `bitetest`. The name says nothing of nilo, which keeps the separation this ADR draws, and it was chosen before the first tag, while a module path could still change at no cost to anyone: once a version is fetched through the module proxy the path is permanent.

**What was rejected (the name):** "nilo-go", the working name until 2026-11-04, because its repository and its package (`nilogo`) differed, a Go package name having no hyphen, and because it read as a port of nilo, which is the worry this ADR answers. "go-bites" as the repository around a `bites` package, for the same mismatch. "tera", which in web development already names a well-known Rust template engine. "leo", because the GitHub organisation `go-leo` already publishes a Go HTTP package under that name. The check behind these was made on 2026-11-04 by sampling GitHub and pkg.go.dev, so it is a claim, not a measurement. The reports and recorded output under `docs/research/` written before the rename keep the name they were written with; only their code was moved to the new module path, so the probes still build.
