# Before 1.0, a breaking change is allowed when it buys a cleaner design, and says what to change

The module stays at v0.x with no promise of stability, for the Go API and for the wire alike. A breaking change that makes the design cleaner is made rather than worked around. **There is no changelog before the first tag** (decided 2026-11-04): nothing has been released, so nobody upgrades from anything and a list of changes has no reader. From the first tag, each release's page under [`docs/releases/`](../releases/) says, for every breaking change since the release before it, what a user has to change.

**The wire is not promised either.** What a client sees (a status, the shape of a problem+json answer, a wire name, a header the framework sends, an error's location or message) may change in any v0.x release, a patch included, under the same rule: it is made when it buys a cleaner design, and its release page says what a client or a test that reads the wire has to change. Decided on 2026-11-02 by the maintainer, settling the roadmap's open question "Wire stability before 1.0". From 1.0 the Go API and the wire behaviour are promised together (roadmap, Milestone 4).

**What was rejected.** A `CHANGELOG.md` kept from the start (until 2026-11-04): its entries piled up under Unreleased for a release that was never tagged, and repeated what the ADRs and the git history already said. Fixing the wire within a minor version (a v0.1.x patch never changes what a client sees) and fixing it from v0.1.0 to 1.0: both protect a deployed API's clients across upgrades, and both would hold a wire fix back behind a version number while the design is still being settled. The cost is borne by the teams who deploy v0.x, who read the release page before upgrading. A version bump follows the size of the change, never the word used for it: a fix is a patch, a feature a minor. A tag is created only when the maintainer asks for it, with the exact version stated first, because a pushed Go tag is permanent once the module proxy has fetched it.
