# The API documentation UI is a module that serves a small page and loads Swagger UI or Scalar from a CDN at a pinned version

`modules/docsui` ([ADR 0070](0070-optional-features-are-modules-under-modules-each-with-its-own-go-mod.md)) has one function, `docsui.Mount(app, "/docs", docsui.Config{SpecURL: "/openapi.json"})`, that registers `GET /docs` serving an HTML page for the document `App.OpenAPI` serves ([ADR 0020](0020-descriptions-come-from-registration-and-later-from-doc-comments.md)), and for Swagger UI `GET /docs/init.js` beside it. The page is built once, when `Mount` runs, and served as fixed bytes, so a request costs what a `Bytes` answer costs ([ADR 0003](0003-the-trade-budget.md)), and nothing in it runs per request. It is opt-in like the document: nothing is mounted by default.

**The interface is not vendored; the browser loads it from a CDN at an exact version.** `Config.UI` is `Swagger` (Swagger UI, the zero value, default 5.34.1 from `swagger-ui-dist`) or `Scalar` (`@scalar/api-reference`, default 1.76.4); `Config.Version` replaces the default and must be an exact version of letters, digits, dots, dashes and plus signs, never a range or a tag such as `latest`, so the page that was tested is the page a browser gets. `Config.CDN` defaults to jsdelivr and is replaced by any `https` base, so an application that wants no third party mirrors the two packages and points the page at its own host. `ScriptIntegrity` and `StyleIntegrity` add Subresource Integrity to the tags; the module cannot compute them (it works offline and a hash is the hash of the bytes at that version), so an application that wants them takes them from the CDN once. Vendoring the assets in the module was rejected: Swagger UI's bundle is over a megabyte and Scalar's more, they would sit in every binary that imports the module and in the module's repository history, and a security fix in either would need a module release instead of a version string.

**The page is CSP-friendly: it contains no inline script and no inline event handler.** Scalar reads its settings from `data-` attributes of its script tag. Swagger UI is started by a four-line script that the module serves from the same origin as `/docs/init.js`, so the policy needs `'self'` and the CDN's origin for `script-src` and never `'unsafe-inline'`. `Mount` sets that policy on the page and the script: `default-src 'none'; script-src 'self' <cdn>; style-src 'self' 'unsafe-inline' <cdn>; img-src 'self' data: https:; font-src 'self' data: <cdn>; connect-src 'self' [the spec's origin]; frame-ancestors 'none'; base-uri 'none'; form-action 'none'`, with `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` and `Cache-Control: no-cache`. `style-src` allows inline styles because both interfaces draw with them; that is the one concession. The title and every value written into the HTML or the script are escaped for the place they land (an HTML attribute, a JSON string in the script), and a version, CDN or integrity value that could end an attribute is refused.

**Its refusals.** `Mount` panics, naming the file and line of the call, for a path that does not start with a slash, ends with one, or holds a wildcard, query or fragment; an empty `SpecURL`, or one that is neither a path nor an `http(s)` URL (`javascript:` is refused); a `UI` that is neither value; a `Version` that is not an exact version; a `CDN` that is not `https`; an integrity value that is not `sha...`. A path another route already has is refused by the router like any other. Route options are the typed routes': `Use` puts an authentication middleware in front of the page, and `docsui` has no option of its own for it, because [ADR 0048](0048-groups-and-the-order-things-run-in.md) already says where middleware goes.

**Scenarios it was put against.** A strict-CSP production site: the page loads with no violation when the CDN origin is allowed, and with `CDN` set to the site's own mirror the policy names only `'self'`. A spec URL with a quote or an angle bracket in it: escaped in the attribute and in the script, tested. A private API: `Use` of a Provider-backed middleware answers 401 before the page. A CDN outage: the page shows nothing; the API is unaffected, since the document is served by the app itself. A version typo: the CDN answers 404 for the script and the page is blank, which no check at Registration can see (the module does not fetch).

**What it fails at.** The two default versions (Swagger UI 5.34.1, Scalar 1.76.4) were the latest on jsDelivr when checked on 2026-11-01, each file answering 200 with its JavaScript or CSS type; a newer release is taken by changing the constant, or per app with `Version`, and nothing checks the CDN at build time. Scalar fetches its fonts and may call its own proxy for "try it" requests; the policy blocks both, so Scalar's fonts fall back to the system's and its proxy is off, which is the safer failure. The page and its script are left out of the app's own OpenAPI document: `Mount` gives both routes `bites.Undocumented()` ([ADR 0069](0069-the-api-document-states-what-a-routes-providers-and-middleware-ask-and-answer-and-a-route-can-be-left-out.md), milestone 3 wave 2); until then they appeared in it as operations (`TestThePageAndItsScriptAreLeftOutOfTheAPIDocument`). The document's `servers` are set by `Info.Servers` ([ADR 0025](0025-no-proxy-is-trusted-by-default.md), 2026-11-02), which the page's tools read for their requests; the page itself fetches `SpecURL`, so behind a prefix the `SpecURL` must carry the prefix.

**Axes:** the core's four are unchanged; the module adds two routes whose answers are fixed bytes (one allocation more than a `Bytes` answer for the copy, [ADR 0043](0043-cookies-and-bodies-other-than-json.md)).

**What was rejected:** serving the UI from the core as `app.Docs(...)` (the core would hold HTML and the knowledge of two front-end packages that change on their schedule); an inline `<script>` with a nonce per request (it makes the page per request, an allocation and a randomness source on a path that is otherwise fixed bytes); ReDoc (not asked for, and the same shape would take it: another value of `UI`).
