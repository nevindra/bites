# Reference

Every exported name of `bites`, `bitetest` and `stdhttp`, one heading each, with its signature, its defaults, what it refuses at Registration and what it does at run time.

**`go doc` reads the same comments.** `go doc github.com/nevindra/bites Page` works from any module that requires bites, and `go doc ./bitetest` from the repository's root. Each module under `modules/` has its own `go.mod` ([ADR 0070](../adr/0070-optional-features-are-modules-under-modules-each-with-its-own-go-mod.md)), so the root module does not contain it and `go doc ./modules/otel` from the root fails with `main module ... does not contain package`: run `go doc .` inside `modules/otel` (or `modules/otel/...`), or `go doc github.com/nevindra/bites/modules/otel` from an application whose `go.mod` requires it.

| Page | Covers |
|---|---|
| [App, groups, options and limits](./app.md) | `New`, `App`, the route methods, `Group`, `Use`, serving on several listeners and Unix sockets, TLS certificates (`Certs`), shutdown, `Option`s, `Limits`, `Gzip` and `Compression`, `TrustedProxies`, `Clock`, naming policies, `RegistrationError` |
| [Input types](./input.md) | the Sections, `Opt`, `Null`, the constraint types, `Form`, `Submitted`, `Raw`, `Upload` and `Part`, and the options that bound a body |
| [Responses](./responses.md) | the status wrappers, `Text`, `Bytes`, `Page`, `File`, `Static`, `Header`, `Cookie`, `OneOf2` to `OneOf4`, `Returns`, `Stream`, `SSE`, `Events` and their errors |
| [Errors](./errors.md) | `StatusError` and its constructors, `Invalid` and `FieldError`, `ErrClientGone` and `Cause`, and the problem+json shape |
| [Middleware](./middleware.md) | `Middleware`, `Request`, `Response`, `Next`, `Use`, `CORS`, `RequestID` and `Timeout` |
| [Observability](./observability.md) | `Observer`, `Outcome`, `WithObserver`, `AccessLog`, `Metrics` and `ServeMetrics`, `Trace` and `WithTraceContext`, `WithHealth`, `WithShutdownDelay` and `SetReady` |
| [Providers](./providers.md) | `Provide` and `Override` on the app, a group and a route |
| [Security](./security.md) | `SecurityHeaders`, `BearerAuth`, `BasicAuth`, `APIKeyAuth`, `RateLimiter`, `Session` and `Sessions`, `CSRF` |
| [WebSockets](./websocket.md) | `WebSocket` routes, `Socket`, `Inbox`, `Topic`, `NewTopic`, `Broker`, close information, and the origin and message limits |
| [OpenAPI](./openapi.md) | `App.OpenAPI`, `Info`, `Summary`, `Description`, `Tag`, `Undocumented` and the `Descriptions` method |
| [bitetest](./bitetest.md) | `Start`, `Server`, `Request`, `Response`, the WebSocket client `WS`, the fake `Clock`, the in-memory `Broker` and the conformance suites of the store interfaces |
| [pgnotify](./pgnotify.md) | the module that carries a Topic between instances over Postgres `LISTEN`/`NOTIFY` |
| [pgsession](./pgsession.md) | the module that keeps sessions in Postgres as an `OwnerSessionStore`, revocable by owner |
| [pgratelimit](./pgratelimit.md) | the module that keeps the buckets of a `RateLimiter` in Postgres as a `RateLimitStore`, so a limit holds across instances |
| [stdhttp](./stdhttp.md) | `Mount`, `MountGroup`, `MountMethods` and `Methods`, for serving a plain `http.Handler` |
| [docsui](./docsui.md) | the module that serves Swagger UI or Scalar for the OpenAPI document |
| [jwt](./jwt.md) | the module that verifies HS256, RS256 and ES256 tokens for `BearerAuth`, with fixed keys or a JWKS |
| [otel](./otel.md) | the module whose Observer records an OpenTelemetry server span for each request |
| [config](./config.md) | the module that fills a typed struct from flags, the environment and files, and lists every wrong setting at once |
| [zstd](./zstd.md) | the module that adds the `zstd` content coding to response compression |
| [brotli](./brotli.md) | the module that adds the `br` content coding to response compression |
| [Tools](./tools.md) | the `bites-doc` and `bites-site` programs |

A heading is the exported name itself, so the anchor of `App.Get` is `app.md#appget`. The guide for each page is linked on its fifth line, and the map of all three layers is [the documentation map](../README.md).
